# Проверка русского форка и Android 11

Дата: 12 ноября 2026. База: upstream `463fa6c`, версия 2.1.5.
Цель первого испытания: X4Q Pro с Android 11 (API 30).

## Исправлено

| Проблема | Изменение |
|---|---|
| Новые экраны почти полностью выпадали из русского словаря | Дополнен словарь настройки, поиска, пульта, виджетов, файлов, обновлений и экранов презентации |
| Русское «Слева» содержало символы другого алфавита | Исправлено, добавлена проверка |
| Ambient Mode назывался спящим режимом | Теперь «Заставка»; Screen Off описывается как выключение экрана, без обещания полного отключения питания |
| Перевод искался по уже собранной строке с номером версии или названием | Сообщения переведены на шаблоны, значения подставляются после перевода |
| Стандартные имена профилей оставались английскими | Переводятся стандартные имена; произвольные пользовательские имена сохраняются |
| Названия стран выводились вместе с кодом языка из неверно истолкованных столбцов | Названия получаются через Locale на языке интерфейса |
| В системных разрешениях не было русских названий служб | Добавлены русские Android-ресурсы для описания службы и названий служб |
| Форк искал обновления оригинала, подписанные другим ключом | API релизов и загрузка APK направлены в Greeg0ry/tvOS-Launcher |
| Caffeine захватывал WakeLock без разрешения | Добавлено нормальное разрешение WAKE_LOCK |
| CleanYourTV считал ошибку команды отключения успешным результатом | Состояние подтверждается ответом PackageManager для конкретного пакета |
| Восстановление очищало список даже для пакетов, которые не удалось включить | Из списка убираются только подтверждённые пакеты; частичный результат показывается счётчиками |
| На Android 11 запрашивалось устаревшее WRITE_EXTERNAL_STORAGE | Для API 30–32 запрашивается чтение, для API 33+ — READ_MEDIA_IMAGES; полный доступ остаётся отдельным явным действием |
| Упаковка зависела от внешней команды zip | Используется jar из уже необходимого JDK |
| По разрешениям APK требовал микрофон, Wi-Fi и геолокационное оборудование | Эти аппаратные возможности отмечены необязательными; подходит для приставки с Ethernet и обычным пультом |
| Старая инструкция отключала конкретный Google-лаунчер и ссылалась на отсутствующий DeviceAdmin | Инструкция переписана для первого испытания с сохранением штатного лаунчера |

## Что проверено автоматически

- Полная сборка Java и DEX через Android SDK 34, JDK 17, без сторонних библиотек.
- Проверка 1120 русских ключей и шаблонов, включая подписи из таблиц настроек.
- 24 проверки подстановки значений, английского и турецкого fallback, стандартных и пользовательских
  имён, успешных и неуспешных ответов PackageManager.
- Подпись APK (v2/v3), выравнивание, пакет, версия, min SDK 24 и target SDK 34.
- Синтаксис Bash и отсутствие ошибок пробелов в diff.

Извлечение ключей и запуск проверки после сборки:

```sh
python3 tools/localization_keys.py --keys > build/localization-keys.txt
SDK="${ANDROID_HOME:-$HOME/Library/Android/sdk}"
mkdir -p build/checks
javac -encoding UTF-8 --release 11 -cp "build/classes:$SDK/platforms/android-34/android.jar" \
  -d build/checks tests/LauncherChecks.java
java -cp "build/checks:build/classes:$SDK/platforms/android-34/android.jar" \
  com.techgenius.tvoslauncher.LauncherChecks build/localization-keys.txt
```

Для фактической сборки и проверок использован уже установленный локальный Docker-образ
`cleanyourtv-android-build:latest` с JDK 17 и SDK 34. APK не содержит нативных библиотек
и не привязан к ARM32/ARM64. PowerShell-скрипт обновлён, но на Windows не запускался.

## Что требует приставки

Успешная компиляция не подтверждает совместимость конкретной прошивки X4Q Pro.
До отключения штатного лаунчера требуется проверить:

1. Установку APK и прохождение настройки пультом без мыши.
2. Кнопку Home из другого приложения и после перезагрузки, возврат после сна.
3. Одиночное, двойное и длинное нажатия, громкость и специальные возможности.
4. Панель поверх видео, доступ к уведомлениям, продолжение просмотра в используемых приложениях.
5. Выбор изображения, папку USB, сохранение и восстановление JSON.
6. Погоду и поиск через доступное приставке подключение, сетевые источники рекомендаций.

Прошивка может ограничивать выбор Home, доступ к уведомлениям и отладку по сети.
Автонастройка требует доступного локального ADB на 5555; протокол Wireless Debugging
с кодом сопряжения и случайным портом этим клиентом не поддерживается.

Веб-панель управления презентациями остаётся на языке оригинала. Названия приложений,
контент внешних сервисов, пользовательские имена и системные экраны прошивки могут иметь
свой язык. Проверка ключей подтверждает наличие переводов, но не проверяет обрезание
длинного текста на телевизоре. Резервная копия JSON переносит настройки, а не изображения
собственных значков и обоев; перед удалением оригинала изображения нужно сохранить отдельно.

Правила доступа к файлам сверены с [изменениями Android 11](https://developer.android.com/about/versions/11/privacy/storage)
и [документацией MANAGE_EXTERNAL_STORAGE](https://developer.android.com/training/data-storage/manage-all-files).
